Twelve calculators, one per stage

Move a slider and see the answer. Each calculator uses the same formula as its stage's Python code, so you can try the method on your own numbers before reading how it works.

Indicative values and synthetic defaults. These are teaching tools, not advice for a real field.

Stage 01 · Land Intelligence & Suitability

How suitable is my plot?

You set
altitude, rainfall, temperature, slope, soil pH, drainage, depth, organic carbon
You get
S1 to N class for teff, wheat and maize by two methods, with the main limit and whether it is fixable

How much water does a hectare need?
