The data spine

Twelve stages only work as one system if each passes a clear, agreed record to the next. This page shows every hand-off: forward through the season above the line, and back through the learning loop below it.

Analogy: a relay race where the baton is a record with a fixed shape. If one runner changes the baton, the next cannot take it. Each record below is defined in the stage's domain model and code.
